# Defensive Security Intro – TryHackMe

**Room Type:** Introduction  
**Category:** Defensive Security (Blue Team)


## What is Defensive Security
Defensive Security focuses on **protecting systems and networks** from cyber attacks.  
It involves monitoring, detecting, and responding to security threats.


## What I Learned
- Difference between **Offensive** and **Defensive** security  
- Role of the **Blue Team** in cybersecurity  
- Importance of monitoring and incident handling


## Key Concepts
- **SOC (Security Operations Center):** Team that monitors security events  
- **SIEM:** Tool used to collect and analyze logs  
- **Incident Response:** Steps taken after detecting a security incident

---

## Takeaway
Defensive Security helps organizations **detect attacks early and reduce damage**.  
It is a critical part of real-world cybersecurity.

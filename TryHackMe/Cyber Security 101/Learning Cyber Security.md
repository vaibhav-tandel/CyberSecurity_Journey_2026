# Learning Cyber Security – TryHackMe

**Room Type:** Beginner  
**Focus:** Cybersecurity domains, career paths, and foundational security concepts

---

## Overview
This room provides a high-level introduction to cybersecurity and its major domains. It helps beginners understand what cybersecurity involves, common roles in the field, and how different areas contribute to protecting systems and data.

## What I Learned
- The main cybersecurity domains such as defensive security, offensive security, and governance
- Common attack motivations and threat actor categories
- Typical career paths in cybersecurity and required skill sets
- The importance of foundational knowledge before specializing

## Tools & Techniques Used
- **Cybersecurity Domains Mapping** – Understanding how different security areas interconnect
- **Threat Awareness** – Recognizing common threats and attacker goals
- **Career Path Exploration** – Identifying roles aligned with technical interests

## Key Concepts Covered
- Cybersecurity fundamentals
- Blue Team vs Red Team
- Threat actors and motivations
- Defensive and offensive security
- Security career pathways

## Takeaway
This lab provides essential orientation for newcomers, helping them understand the cybersecurity landscape before diving into technical skills.

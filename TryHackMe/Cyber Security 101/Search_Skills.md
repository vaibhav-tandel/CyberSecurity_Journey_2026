# Search Skills – TryHackMe

**Room Type:** Intro  
**Focus:** Search & OSINT Skills



## What I Learned
- How to search information efficiently
- Using search operators and filters
- Importance of OSINT in cybersecurity


## Key Techniques
- `" "` for exact search  
- `site:` to limit results to a site  
- `filetype:` to find specific files  


## Useful Websites
- **Shodan** – Search engine for internet-connected devices  
- **Censys** – Finds exposed hosts, services, and certificates  
- **VirusTotal** – Analyzes files and URLs for malware  
- **Have I Been Pwned** – Checks if emails or passwords were leaked  
- **Whois Lookup** – Finds domain ownership and registration details

## Takeaway
Search skills help in **information gathering and reconnaissance**.

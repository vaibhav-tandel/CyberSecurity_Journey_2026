# Windows Command Line – TryHackMe

**Room Type:** Beginner  
**Focus:** Windows Command Prompt (CMD)

---

## Overview
This room introduces the Windows Command Line and essential commands used for system navigation, management, and troubleshooting.


## What I Learned
- How to navigate the file system using CMD
- How to view, create, and manage files and folders
- How to run system and network commands


## Basic Navigation Commands
- `dir` – list files and directories  
- `cd` – change directory  
- `cls` – clear the screen  
- `tree` – display directory structure  


## File & Folder Management
- `mkdir` – create a directory  
- `rmdir` – delete a directory  
- `copy` – copy files  
- `move` – move files  
- `del` – delete files  
- `type` – view file content  


## System & Network Commands
- `ipconfig` – view network configuration  
- `ping` – test network connectivity  
- `netstat` – display network connections  
- `tasklist` – view running processes  


## Command Chaining & Help
- `&&` – run next command if previous succeeds  
- `|` – pipe output to another command  
- `help` / `command /?` – view command usage  

---

## Takeaway
Windows command-line skills are important for **system administration, automation, and cybersecurity tasks**.

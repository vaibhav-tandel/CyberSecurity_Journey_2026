# Windows Fundamentals 1 – TryHackMe

**Room Type:** Beginner  
**Focus:** Windows Operating System Basics


## Overview
This room introduces the Windows operating system, its structure, and core components used for system management and security.


## What I Learned
- Basic structure of the Windows OS
- Difference between files, folders, and system components
- How Windows manages users and permissions
- Importance of built-in Windows tools


## Key Windows Components
- **Desktop & File Explorer** – Used to navigate files and folders  
- **Control Panel** – Used to configure system settings  
- **Settings App** – Modern interface for system configuration  
- **Task Manager** – Displays running processes, services, and performance  
- **Registry** – Central database storing system and application settings  


## User Accounts & Permissions
- **Administrator** – Full system access  
- **Standard User** – Limited permissions  
- **Guest** – Minimal access  
- File permissions control who can read, write, or execute files


## Important System Locations
- `C:\Windows` – Core operating system files  
- `C:\Program Files` – Installed applications (64-bit)  
- `C:\Users` – User profiles and personal data  


## Security Concepts
- Importance of user privilege separation  
- Why system files should not be modified by normal users  
- How permissions help protect the OS from misuse

## Takeaway
Understanding Windows fundamentals is essential for **system administration, digital forensics, and cybersecurity defense**.

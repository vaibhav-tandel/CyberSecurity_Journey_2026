**Room Type:** Beginner

## Overview
This room covers core Windows configuration tools and system management features used by administrators and security professionals.


## What I Learned
- How Windows manages system settings and services
- How to view and control running processes
- How to configure startup behavior and system information


## System Configuration Tools
- **System Information (`msinfo32`)** – Displays hardware, software, and environment details  
- **System Configuration (`msconfig`)** – Manages startup services and boot options  
- **Task Manager** – Monitors processes, performance, startup apps, and services  


## Services & Startup
- **Windows Services** run in the background to support OS functions  
- Services can be **started, stopped, or disabled**  
- Startup applications affect system boot time


## Windows Update
- Keeps the system **secure and stable**
- Installs security patches and feature updates
- Regular updates reduce vulnerabilities


## UAC (User Account Control)
- Prompts before making system-level changes  
- Helps prevent unauthorized modifications  
- Adds an extra layer of security

---

## Takeaway
Windows configuration tools are essential for **system hardening, troubleshooting, and security monitoring**.

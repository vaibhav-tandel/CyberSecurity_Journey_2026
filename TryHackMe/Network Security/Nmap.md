# Nmap – TryHackMe

**Room Type:** Beginner  
**Focus:** Network scanning, service discovery, and basic enumeration using Nmap

---

## Overview
This room introduces Nmap as a core network reconnaissance tool used in cybersecurity. It focuses on identifying open ports, running services, and basic host information to understand an attack surface.

## What I Learned
- The purpose of network scanning in both offensive and defensive security
- How different Nmap scan types affect speed, accuracy, and detectability
- How to interpret Nmap output to identify exposed services
- Why port and service enumeration is critical before deeper analysis or exploitation

## Tools & Techniques Used
- **Nmap** – Network scanner used to discover hosts, open ports, and services
- **Port Scanning** – Identifying listening ports on a target system
- **Service Enumeration** – Determining what services and versions are running
- **Host Discovery** – Checking whether systems are online and reachable

## Key Concepts Covered
- TCP and UDP ports
- Open, closed, and filtered port states
- Network reconnaissance
- Attack surface identification
- Blue Team and Red Team relevance of scanning

## Takeaway
This lab teaches foundational reconnaissance skills using Nmap, which are essential for understanding network exposure and strengthening security defenses.

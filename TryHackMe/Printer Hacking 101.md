# Printer Hacking 101 – TryHackMe

**Room Type:** Beginner  
**Focus:** Printer security, common misconfigurations, and attack surface awareness

---

## Overview
This room introduces printers as often-overlooked network devices with real security risks. It explains how insecure printer configurations can be abused and why printers should be treated like any other networked system.

## What I Learned
- Why printers are valuable targets in enterprise networks  
- Common printer services and protocols that expose attack surfaces  
- How misconfigured printers can leak sensitive data or be abused for persistence  
- The importance of asset visibility and patching for non-traditional endpoints  

## Tools & Techniques Used
- **Network Enumeration** – Identifying printers and exposed services on a network  
- **Service Identification** – Understanding printer-related ports and protocols  
- **Configuration Review** – Recognizing insecure default settings  
- **Security Hardening Concepts** – Reducing risk through access control and updates  

## Key Concepts Covered
- Networked device security
- Printer protocols (IPP, LPD, JetDirect)
- Default credentials and misconfigurations
- Data leakage via printers
- Peripheral attack surfaces

## Takeaway
This lab highlights how neglected devices like printers can introduce serious security risks if not properly monitored and secured.

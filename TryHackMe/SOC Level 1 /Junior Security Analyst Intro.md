# Junior Security Analyst Intro – TryHackMe

**Room Type:** Intro
## Overview
This room explains the role of a Junior Security Analyst and how they help detect, analyze, and respond to security threats.

---

## What I Learned
- Responsibilities of a Junior Security Analyst
- How security alerts are monitored and investigated
- Importance of following procedures and documentation


## Key Responsibilities
- Monitor security alerts and logs  
- Analyze suspicious activity  
- Escalate incidents when required  
- Follow incident response procedures  


## Common Tools Used
- SIEM platforms  
- Log monitoring tools  
- Ticketing systems  

---

## Takeaway
Junior Security Analysts play a key role in **early threat detection and incident response**.
